CORRECTED BASELINE — the figures published before this run measured the wrong
quantity, and are superseded.

tools/pacing.js used to report `V6_ACHIEVEMENTS.filter(a => a.test(st)).length`
— it re-ran every test against the FINAL state and counted what happened to be
true at that instant. The game does not work that way: v6AchievementsTick
latches, and the game's own displays (the end card, the persisted hall entry)
count the latched map. Twelve of the thirty-nine records are transient
conditions that bank the first time they flicker and are usually false again by
the end, so they were invisible to the old figure — and the longer the campaign,
the more turns it has to flicker, so the error was WORSE for the long options.

Old figures (superseded): short 8%, century 18-23%, epic 21-28%.
Corrected below:         short 10-15%, century 18-28%, epic 21-31%.

The gap is real and roughly two to one, but it is smaller than reported and it
sits almost entirely at SHORT — the century already matches the epic set almost
record for record.
